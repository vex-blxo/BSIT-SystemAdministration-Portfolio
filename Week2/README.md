## Project Overview
This project proposes an initial IT infrastructure for ABC Startup Solutions, a fictional software development startup with 20 employees on one office floor.

## Learning Objectives
- Analyze the IT needs of a small business.
- Prepare hardware, software, and networking inventories.
- Design and explain an enterprise network topology.
- Research system administration roles and example certifications.
- Document technical decisions in Markdown.

## Company Scenario
IT has 5 employees, HR has 4, Finance has 5, and Sales has 6. The company starts with no computers, server, network, internet infrastructure, or security policies.

## Hardware Inventory Summary
Proposed baseline: 20 desktops, 5 laptops, 1 server, 1 router, 1 managed switch, 2 printers, 2 UPS units, 2 access points, 1 NAS, 2 encrypted external backup drives, 20 monitors, and supporting cabling/cabinet equipment.

## Software Inventory Summary
Windows 11 Pro, Ubuntu Server LTS, Microsoft 365 Apps/Office, Visual Studio Code, Git, GitHub Desktop, VirtualBox, Chrome, Microsoft Defender, AnyDesk (business license), and 7-Zip. Verify versions and licenses before deployment.
